# Historical modeling source

This directory preserves 59 authored scripts recovered from output folders, five recovered shell scripts, and three later source revisions. Current implementation entry points remain in the parent `scripts/` directory.

The directory layout groups historical variants by their original object or scene project. These files retain version-specific algorithms and can require previously generated assets, installed dependencies, or original stage ordering. They are not a collection of generated models.

Source paths, checksums, and changes are recorded in [the modeling audit](../../docs/modeling/README.md).
